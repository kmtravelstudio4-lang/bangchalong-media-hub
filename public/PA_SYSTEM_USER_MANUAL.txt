================================================================================
          คู่มือการใช้งานระบบประเมินข้อตกลงในการพัฒนางาน (ว.PA)
                 โรงเรียนวัดบางโฉลงใน สพป.สมุทรปราการ เขต 2
================================================================================

ระบบนี้พัฒนาขึ้นเพื่ออำนวยความสะดวกให้แก่ คณะครู, กรรมการประเมิน ว.PA, 
และผู้บริหารสถานศึกษา ในการจัดการข้อมูล ส่งเอกสาร ตรวจประเมิน และสรุปผล 
ตามเกณฑ์ ก.ค.ศ. (ว9/2564) อย่างเป็นระบบ โปร่งใส และรวดเร็ว

--------------------------------------------------------------------------------
สารบัญ
--------------------------------------------------------------------------------
1. บทบาทผู้ใช้งานในระบบ
2. คู่มือสำหรับ "ครูผู้รับการประเมิน" (Teacher Role)
   - 2.1 การเข้าสู่ระบบครู
   - 2.2 การกรอกและอัปเดตข้อมูลข้อตกลง PA (PA 1/ส)
   - 2.3 การแนบลิงก์คลิปวิดีโอการสอน (Active Learning) และเอกสารแผน
   - 2.4 การดาวน์โหลดเอกสารแบบฟอร์ม PA และเครื่องมือช่วยเหลือ
3. คู่มือสำหรับ "คณะกรรมการประเมิน ว.PA" (PA Committee Role)
   - 3.1 การเข้าสู่ระบบกรรมการประเมิน
   - 3.2 แดชบอร์ดติดตามความคืบหน้ารายบุคคล
   - 3.3 ระบบตรวจประเมินแบบแยกหน้าจอ (Split-Screen Evaluation)
   - 3.4 การตรวจเอกสาร PA และคลิปการสอน พร้อมระบบข้อเสนอแนะสำเร็จรูป
   - 3.5 การให้คะแนนและการสรุปผลอนุมัติ
4. คู่มือสำหรับ "ผู้บริหารและแอดมิน" (Admin / Management Role)
   - 4.1 การดูรายงานสรุปสถิติภาพรวมโรงเรียน
   - 4.2 การพิมพ์และส่งออกรายงานสรุปผล ว.PA
5. การแก้ไขปัญหาเบื้องต้นและการติดต่อช่วยเหลือ

================================================================================
1. บทบาทผู้ใช้งานในระบบ
================================================================================
ระบบแบ่งสิทธิ์การใช้งานออกเป็น 3 กลุ่มหลัก:
1) ครูผู้รับการประเมิน (Teacher): ส่งข้อมูล PA, คลิปวิดีโอ, แผนการสอน, ตรวจสอบผล
2) กรรมการประเมิน (PA Committee): ตรวจเอกสาร, ชมคลิปการสอน, ให้คะแนนและข้อเสนอแนะ
3) ผู้บริหาร/แอดมิน (Admin/Executive): ตรวจสอบภาพรวมทั้งโรงเรียน, ส่งออกรายงาน

================================================================================
2. คู่มือสำหรับ "ครูผู้รับการประเมิน" (Teacher Role)
================================================================================

2.1 การเข้าสู่ระบบครู
--------------------------------------------------------------------------------
- ไปที่เมนู "เข้าสู่ระบบครู" (มุมบนขวา หรือแถบเมนูด้านล่างบนมือถือ)
- เลือกรายชื่อของคุณครู หรือกรอกรหัสผ่านประจำตัวครู (Default: 1234 หรือรหัสที่ตั้งไว้)
- เมื่อเข้าสู่ระบบสำเร็จ จะปรากฏแถบ "ห้องทำงานครู" (Teacher Dashboard)

2.2 การกรอกและส่งข้อมูลข้อตกลง PA
--------------------------------------------------------------------------------
1. เข้าไปที่เมนู "ข้อตกลง PA" หรือ "ห้องทำงานครู"
2. เลือกแท็บ "แก้ไขข้อมูล PA ของฉัน"
3. กรอกข้อมูลสำคัญ ได้แก่:
   - รอบปีการศึกษาที่จัดทำข้อตกลง (เช่น ปีการศึกษา 2569)
   - ประเด็นท้าทายในการพัฒนาผลลัพธ์การเรียนรู้ของผู้เรียน (Challenge Title)
   - รายละเอียดประเด็นท้าทาย, วิธีดำเนินการ, และผลลัพธ์ที่คาดหวัง
4. ลิงก์เอกสารข้อตกลง PA (Google Drive / OneDrive / Cloud PDF)
5. ลิงก์คลิปวิดีโอบันทึกการจัดการเรียนรู้ (YouTube Link หรือ Drive)
6. บันทึกข้อมูล ระบบจะปรับสถานะเป็น "ส่งผลงานเรียบร้อยแล้ว" (Completed)

2.3 การติดตามผลการประเมิน
--------------------------------------------------------------------------------
- คุณครูสามารถดูสถานะการตรวจของคณะกรรมการประเมินทั้ง 3 ท่านได้แบบ Real-time
- สามารถเปิดอ่านข้อเสนอแนะ (Feedback) เชิงสร้างสรรค์ที่กรรมการแต่ละท่านบันทึกไว้

2.4 การดาวน์โหลดแบบฟอร์มทางการ
--------------------------------------------------------------------------------
- ที่แท็บ "แบบฟอร์มและเอกสาร PA" ครูสามารถดาวน์โหลดแบบฟอร์มทางการ ก.ค.ศ. เช่น:
  * แบบฟอร์ม PA 1/ส (ข้อตกลงในการพัฒนางาน)
  * แบบฟอร์ม PA 2/ส (แบบประเมินผลการพัฒนางาน)
  * แบบฟอร์ม PA 3/ส (แบบสรุปผลการประเมิน)
  * คู่มือการประเมินตามเกณฑ์ ว9/2564

================================================================================
3. คู่มือสำหรับ "คณะกรรมการประเมิน ว.PA" (PA Committee Role)
================================================================================

3.1 การเข้าสู่ระบบกรรมการประเมิน
--------------------------------------------------------------------------------
- ไปที่เมนู "ข้อตกลง PA" -> เลือกปุ่ม "สำหรับกรรมการประเมิน PA"
- เลือกรายชื่อกรรมการที่ท่านสังกัด (เช่น ผู้อำนวยการโรงเรียน, ผู้ทรงคุณวุฒิ, ศึกษานิเทศก์)
- กรอกรหัส PIN สำหรับกรรมการ (Default PIN: 1234)

3.2 แดชบอร์ดคณะกรรมการ (Committee Workspace)
--------------------------------------------------------------------------------
- หน้าจอจะแสดงรายชื่อครูทุกคนในโรงเรียน แยกตามกลุ่มสาระฯ และวิทยฐานะ
- สัญลักษณ์ระบุสถานะ:
  * สีเขียว (ตรวจครบถ้วน): ตรวจเอกสารและคลิปวิดีโอเรียบร้อยแล้ว
  * สีเหลือง (รอดำเนินการ): ครูส่งผลงานแล้ว รอให้กรรมการเข้าตรวจ
  * สีเทา (ยังไม่ส่ง): ครูยังไม่ได้แนบลิงก์เอกสารหรือคลิปการสอน

3.3 โหมดตรวจประเมินแยกหน้าจอ (Split-Screen Evaluation)
--------------------------------------------------------------------------------
เมื่อคลิกปุ่ม "ตรวจประเมิน" ที่รายชื่อครู ระบบจะเปิดหน้าต่างตรวจประเมินอัจฉริยะ:
- ด้านซ้าย: แสดงเครื่องเล่นคลิปวิดีโอการสอน (YouTube/Drive) และปุ่มเปิดแผนการสอน
- ด้านขวา: แบบฟอร์มการตรวจเช็กลิสต์และบันทึกคะแนน
- ฟังก์ชันพิเศษ:
  * ตรวจเอกสาร PA (Check เอกสารสมบูรณ์)
  * ตรวจคลิปการสอน Active Learning (Check จัดการเรียนรู้เชิงรุก)
  * บันทึกคะแนนประเมิน (0 - 100 คะแนน หรือเลือกชุดคะแนนแนะนำ 75, 80, 85, 90, 95, 100)
  * ข้อเสนอแนะสำเร็จรูป (Feedback Presets): สามารถคลิกเพื่อเพิ่มข้อคิดเห็นเชิงวิชาการ
    ได้อย่างรวดเร็ว หรือพิมพ์ข้อความเพิ่มเติมตามดุลยพินิจ
- เมื่อตรวจเสร็จ ให้คลิกปุ่ม "บันทึกผลการประเมิน" ข้อมูลจะถูกซิงค์เข้าสู่ระบบทันที

================================================================================
4. คู่มือสำหรับ "ผู้บริหารและแอดมิน" (Executive / Admin Role)
================================================================================

4.1 การดูรายงานและสถิติภาพรวม (PA Overview Dashboard)
--------------------------------------------------------------------------------
- เข้าสู่ระบบแอดมิน หรือเข้าหน้า "แดชบอร์ด ว.PA"
- ระบบแสดงผลสรุปสถิติอัตโนมัติ:
  * จำนวนครูที่ส่งผลงานครบถ้วน (ร้อยละความสำเร็จ)
  * จำนวนครูที่ผ่านการตรวจรับรองครบจากกรรมการทุกท่าน
  * กราฟและตารางจำแนกตามกลุ่มสาระการเรียนรู้

4.2 การพิมพ์และส่งออกผลการประเมิน
--------------------------------------------------------------------------------
- สามารถคลิกปุ่ม "พิมพ์ / พิมพ์รายงานสรุป" เพื่อพิมพ์รายงานสรุปผลสำหรับนำเสนอ
  ที่ประชุมคณะกรรมการสถานศึกษา หรือเก็บเป็นหลักฐานงานบุคคล
- ข้อมูลมีความถูกต้อง ตรงตามไฟล์เอกสารและคลิปของครูแต่ละท่าน 100%

================================================================================
5. คำแนะนำและข้อกำหนดทางเทคนิค
================================================================================
1. ลิงก์คลิปวิดีโอ:
   - แนะนำให้อัปโหลดบน YouTube (ตั้งค่าเป็น Unlisted หรือ Public) 
   - หรือ Google Drive (ตั้งค่าสิทธิ์การเข้าถึงเป็น "ทุกคนที่มีลิงก์มีสิทธิ์ดู")
2. ลิงก์เอกสารแผนการสอน / PA 1/ส:
   - แนะนำให้อัปโหลดเป็นไฟล์ PDF บน Google Drive เพื่อให้เปิดอ่านได้ทันทีบนทุกอุปกรณ์
3. การใช้งานบนสมาร์ทโฟนและแท็บเล็ต:
   - ระบบรองรับทั้ง iOS (Safari / Chrome) และ Android (Chrome)
   - กรรมการสามารถตรวจประเมินและดูคลิปผ่าน iPad หรือแท็บเล็ตได้อย่างราบรื่น
